一、{{ }} 插值 —— 显示变量

把 data 里的变量显示出来，可以写表达式。

<!-- 变量、对象字段、表达式、三元 --> <span>{{ userName }}</span> <span>{{ user.name }}</span> <span>{{ 1 + 1 }}</span> <span>{{ status === 1 ? '在职' : '离职' }}</span>
渲染结果：
用户名：{{ userName }} ｜ 姓名：{{ user.name }} ｜ 1+1 = {{ 1 + 1 }} ｜ 状态：{{ status === 1 ? '在职' : '离职' }}

二、v-if / v-show —— 条件渲染

点下方按钮切换 showFlag，观察 v-if 和 v-show 的区别。

<div v-if="showFlag">我用 v-if，为 false 时 DOM 里【没有我】</div> <div v-show="showFlag">我用 v-show，为 false 时我只是【隐藏了】</div>
渲染结果（开关 showFlag = {{ showFlag }}）：
✅ v-if 显示：DOM 里有这个节点
✅ v-show 显示：DOM 里有这个节点
（两个都消失时，打开 F12 → Elements 查看：v-if 的节点被移除了，v-show 的节点还在但 style="display:none"）

三、v-for —— 循环渲染

遍历 userList 数组，每个用户渲染一行。记得加 :key。

<div v-for="u in userList" :key="u.id">{{ u.id }} - {{ u.name }}（{{ u.age }}岁）</div>
渲染结果：
{{ u.id }} - {{ u.name }}（{{ u.age }}岁）
💡 对应 Java：for (User u : userList) { ... }。:key="u.id" 是唯一标识，用主键不用下标。

四、v-model —— 双向绑定

在输入框敲字，下面实时显示 inputValue 的值 —— 输入框和数据自动同步。

<input v-model="inputValue" /> <p>你输入的是：{{ inputValue }}</p>
渲染结果：

你输入的是：{{ inputValue || '（还没输入）' }}

五、:prop（v-bind）—— 动态绑定属性

加冒号 = 传变量；不加 = 传字符串。观察按钮文字和禁用状态是动态的。

<!-- :title 传变量 buttonTitle；:disabled 传变量 isDisabled --> <button :title="buttonTitle" :disabled="isDisabled">鼠标悬停看我</button>
渲染结果（按钮 title 是动态的，鼠标悬停可看到）：
buttonTitle = "{{ buttonTitle }}"，isDisabled = {{ isDisabled }}
💡 不加冒号 title="buttonTitle" 会是字符串 "buttonTitle"；加冒号 :title="buttonTitle" 才是变量值。

六、@event（v-on）—— 绑定事件

点按钮触发方法，方法里改数据，页面自动更新。下面 clickCount 每次点击 +1。

<button @click="handleClick">点我</button> <p>点击次数：{{ clickCount }}</p>
渲染结果：
点击次数：{{ clickCount }}

七、v-html —— 渲染 HTML（了解）

{{ }} 会把内容当纯文本，v-html 渲染真 HTML。⚠️ 有 XSS 风险。

<!-- {{ }} 转义成纯文本；v-html 渲染成红色 --> <div>{{ htmlContent }}</div> <div v-html="htmlContent"></div>
渲染结果：
用 {{ }} 显示：{{ htmlContent }}
用 v-html 显示：

一、Day01 的写法：手动操作 DOM（命令式）

这是你前四天学的思路：数据一变，要手动找到元素、手动改。

<button onclick="add()">+1</button> <div id="count">0</div> <script> let count = 0; function add() { count++; // ❌ 手动找到元素，手动改文字 —— 累、易漏 document.getElementById('count').textContent = count; } </script>

二、Vue 的写法：声明式 + 响应式

你只声明"显示 count"，点按钮改 count，页面自动更新。全程没有 getElementById。

<div>{{ count }}</div> <!-- 声明：显示 count --> <button @click="count++">+1</button> <!-- 点击：count 自增 --> <button @click="count--">-1</button> <button @click="reset">重置</button> <script> new Vue({ el: '#app', data() { return { count: 0 }; }, // 数据在这 methods: { reset() { this.count = 0; }, // 方法在这 }, }); </script>

三、实际运行：点按钮，看 {{ count }} 自动变

下面这个计数器就是 Vue 渲染的。点 +1/-1，数字立刻变 —— 这就是"响应式"。

{{ count }}
💡 验证响应式：打开 F12 → Elements，找到 <span class="counter-num">， 点 +1，观察它的文字自动从 0 变成 1。你没有写任何一行更新 DOM 的代码，Vue 帮你做了。

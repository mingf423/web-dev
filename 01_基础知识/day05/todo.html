待办列表 —— 综合练习

一个页面串起 v-model + v-for + v-if + @click + {{ }}。动手玩：添加、完成、删除。

<!-- ① v-model 绑定输入框 --> <input v-model="newTodo" @keyup.enter="addTodo" /> <button @click="addTodo">添加</button> <!-- ② v-for 循环列表，@click 完成/删除 --> <li v-for="todo in todos" :key="todo.id"> {{ todo.text }} <span @click="removeTodo(todo.id)">删除</span> </li> <!-- ③ v-if 空状态提示 --> <div v-if="todos.length === 0">暂无待办</div> <!-- ④ {{ }} 统计剩余数（组合了 Day03 的 filter）--> 剩余 {{ todos.filter(t => !t.done).length }} 项未完成
共 {{ todos.length }} 项，剩余 {{ todos.filter(t => !t.done).length }} 项未完成
  • {{ todo.text }} 删除
暂无待办，先添加一条吧～
💡 todos.filter(t => !t.done).length 就是 Day03 学的数组方法，写在模板里也能用。 不过更推荐用 computed（Day06 会讲），因为 computed 有缓存、更高效。

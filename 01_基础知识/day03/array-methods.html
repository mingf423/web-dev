准备数据：一个用户数组

项目里这就是接口返回的 res.data.records。

💡 打开浏览器 F12 → Console，也能看到每次操作的 console.log 输出。

一、.map() —— 转换每个元素（≈ stream().map()）

把每个用户对象换成「姓名」，返回新数组，长度不变。

// 提取所有用户名 const names = users.map(u => u.name);
输出：

二、.filter() —— 过滤（≈ stream().filter()）

只保留在职用户（status === 1），返回的新数组可能变短。

// 只保留在职用户 const active = users.filter(u => u.status === 1);
输出：

三、.find() —— 查找单个元素（≈ findFirst()）

找到第一个满足条件的元素，找不到返回 undefined。

// 找到 id 为 3 的用户 const user = users.find(u => u.id === 3); // 找一个不存在的 id const none = users.find(u => u.id === 999);
输出：

四、.sort() —— 排序（≈ sorted()）

按年龄从小到大排序。注意：sort 会原地改数组，所以先 [...users] 复制一份。

// 按年龄升序（a.age - b.age） const byAge = [...users].sort((a, b) => a.age - b.age); // 按年龄降序 const byAgeDesc = [...users].sort((a, b) => b.age - a.age);
升序输出：

五、.forEach() —— 纯遍历（≈ for 循环）

不返回新数组，只是挨个执行一次。

users.forEach(u => { console.log(`${u.name} 今年 ${u.age} 岁`); });
输出：

六、⭐ 方法链：组合拳（项目里最常见）

一句话完成「过滤在职用户 → 提取 id → 排序」，这就是 Java Stream 的链式写法。

// 过滤在职 → 提取 id → 排序 const ids = users .filter(u => u.status === 1) .map(u => u.id) .sort((a, b) => a - b);
输出：
💡 再对比一下 Java：
users.stream().filter(u -> u.getStatus()==1).map(User::getId).sorted().collect(toList())

七、.reduce() —— 累加/汇总（≈ stream().reduce()）

把数组汇总成一个值，比如求年龄总和、平均值。

// 求所有用户年龄总和（0 是初始值） const totalAge = users.reduce((sum, u) => sum + u.age, 0); // 求平均年龄 const avgAge = totalAge / users.length;

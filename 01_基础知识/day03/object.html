四、展开运算符 ... —— 复制与合并

项目里最常见的用法：复制对象并顺便改个字段。

// 合并对象：复制 baseConfig，覆盖 port const baseConfig = { host: 'localhost', port: 8080, timeout: 3000 }; const devConfig = { ...baseConfig, port: 9090 }; // 合并数组 const merged = [...[1,2], ...[3,4]]; // [1,2,3,4] // 复制数组（不污染原数组） const copy = [...[5,6,7]];
输出：
💡 项目里的 this.queryParam = { ...this.queryParam, pageNo: 1 } 就是「复制一份 queryParam，把 pageNo 改成 1」。

五、可选链 ?. —— 防空指针

任何一环是 null/undefined 就短路返回 undefined，不报错。

// 有公司信息的用户 const u1 = { name: '张三', company: { address: { city: '杭州' } } }; // 没有公司信息的用户（company 是 undefined） const u2 = { name: '李四' }; // ❌ 直接访问会报错 // u2.company.address.city → Cannot read properties of undefined // ✅ 用可选链，安全访问 const city1 = u1?.company?.address?.city; // '杭州' const city2 = u2?.company?.address?.city; // undefined（不报错）

六、空值合并 ?? —— 给个默认值

左边是 null/undefined 时用右边，类似 Optional.orElse()。

const nickname1 = u1?.nickname ?? '未设置'; // '未设置' const city3 = u2?.company?.address?.city ?? '未知城市'; // '未知城市'

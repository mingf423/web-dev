Day03 综合练习：处理一份用户数据

数据是项目里最常见的「用户列表」，假设它来自接口 res.data.records。

任务 1：筛选在职用户（filter）

需求：status === 1 表示在职，status === 0 表示离职。请用 filter 找出所有在职用户。
提示：参考代码已实现，你可以打开 F12 → Sources 打断点，观察每一步的中间结果。

任务 2：提取所有姓名（map）

需求：从「在职用户」里提取出所有人的姓名，得到 ['张三', '李四', ...]。
提示：可以在任务 1 的结果上继续 .map(u => u.name)，体验方法链。

任务 3：按年龄排序（sort）

需求：把所有用户按年龄从大到小排序。
提示：注意先 [...users] 复制，避免 sort 改掉原数组。

任务 4：找出年龄最大的在职用户（组合拳）

需求：组合 filter + sort，找出在职用户里年龄最大的那个。
提示：先 filter 出在职的，再按年龄降序，取 [0]。

任务 5：解构 + 模板字符串打印（综合）

需求：用 forEach + 解构 + 模板字符串，逐行打印「姓名 今年 年龄 岁，状态 在职/离职」。
提示：forEach(({ name, age, status }) => { ... })，注意参数就是解构。

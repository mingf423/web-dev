一、position: relative（相对定位）

元素仍占据原位置，但可以相对于自己的原位置偏移 top/left/right/bottom。

← 这是 relative 元素原本的位置（已被偏移）
position: relative; top: 20px; left: 30px

👆 元素视觉上移动了，但它原始位置的空间仍然保留（上面的虚线框）。 relative 最大的用途不是偏移自己，而是给 absolute 子元素做锚点。

二、position: absolute + relative 父元素 ⭐ 最重要

absolute 元素脱离正常流，相对于最近的定位祖先（非 static）定位。 最常见组合：父 relative + 子 absolute。

三、position: fixed（固定定位）

相对于浏览器窗口固定，滚动页面也不动。常用于顶部导航栏、底部操作栏。

👇 页面底部有一条蓝色固定条（就是这个 fixed 元素），滚动页面它始终在底部。

四、position: sticky（粘性定位）

滚动前正常排列，滚动超过阈值后固定不动。常用于表头固定。

五种 position 速查

值 参照物 是否脱离文档流 典型场景
static 正常流 否 默认值，99% 的元素
relative 自己原位置 否（保留占位） 给 absolute 子元素做锚点
absolute 最近的定位祖先 是（不占空间） 角标、下拉菜单、弹窗
fixed 浏览器视口 是 固定导航、底部操作栏
sticky 滚动容器 否（滚动到阈值前） 表头跟随、侧边栏

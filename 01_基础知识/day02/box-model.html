一、盒模型四层结构

每个元素都是一个矩形盒子，从外到内：margin → border → padding → content

width: 200px
■ margin（外边距） ■ border（边框） ■ padding（内边距） ■ content（内容区）

👆 打开 F12 → Elements，鼠标悬停在蓝色盒子上，可以看到浏览器标注的四层区域。

二、content-box vs border-box

两者 CSS 声明完全一样（width:200px, padding:20px, border:5px），但实际占用宽度不同！

content-box（默认）
内容区
⚠ 实际占宽 = 200 + 20×2 + 5×2 = 250px
width 只算内容区
border-box（推荐）
内容区
✅ 实际占宽 = 200px（含 padding+border）
width = 内容+padding+border

三、margin 的三个关键特性

3.1 margin: auto 实现水平居中

margin: 0 auto → 水平居中

3.2 上下 margin 会"折叠"（取最大值）

box-a: margin-bottom: 30px
box-b: margin-top: 30px

⚠ 两个盒子间距不是 30+30=60px，而是取最大值 = 30px。这就是 margin 折叠。

一、display: block（块级元素）

独占一整行，可以设置 width / height。<div> <p> <h1> 默认就是 block。

Block 1 — width: 200px
Block 2 — width: 200px
Block 3 — width: 200px

👆 即使只有 200px 宽，每个仍独占一行，下一个会换到新行。

二、display: inline（行内元素）

不换行，但 无法设置 width / height。<span> <a> 默认就是 inline。

Inline-A Inline-B Inline-C

❌ 即使写了 width:200px; height:44px，对 inline 元素也不生效！尺寸由内容决定。

三、display: inline-block（行内块元素）

既能在同一行排列，又能设置 width / height。<button> <input> 默认就是 inline-block。

Btn-A
Btn-B
Btn-C
Btn-D

✅ 不换行 + 有宽高 = inline-block。项目中 el-button 就是这样。

四、常见 HTML 标签的默认 display 值

标签 默认 display 能设宽高？ 换行？
<div> <section> <header> block ✅ 能 ✅ 换行
<p> <h1>~<h6> <ul> block ✅ 能 ✅ 换行
<span> <a> <em> inline ❌ 不能 ❌ 不换行
<button> <input> <select> inline-block ✅ 能 ❌ 不换行（但宽度不够会换）
<img> <video> inline（替换元素） ✅ 能（特殊） ❌ 不换行

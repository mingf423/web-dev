父子组件通信：props 下传 + $emit 上抛

父组件通过 :title="parentTitle" 把数据传给子组件（props 下传）； 子组件通过 $emit('notify', ...) 抛事件通知父组件（$emit 上抛）。

<!-- 父组件模板 --> <child-card :title="parentTitle" @notify="handleNotify" /> │ props 下传 │ $emit 上抛 // 子组件：声明接收 title，用 $emit 抛事件 Vue.component('child-card', { props: ['title'], methods: { notify() { this.$emit('notify', '你好，父组件！'); }, }, }); // 父组件：监听 notify 事件 methods: { handleNotify(msg) { this.received = msg; this.count++; }, }
👑 父组件
修改父组件数据 parentTitle：
收到的子组件消息：{{ received || '（还没收到）' }} 收到次数：{{ count }}
▼ props 下传（parentTitle → 子组件的 title）
🧒 子组件（child-card）
▲ $emit 上抛（子组件 notify → 父组件 handleNotify）
💡 操作试试：① 改上面的输入框，子组件里显示的 title 跟着变（父 → 子，props）。 ② 点子组件里的「通知父组件」按钮，父组件的「收到消息」和「次数」变化（子 → 父，$emit）。
⚠️ 单向数据流：子组件不能直接改 props（title），想改只能 $emit 让父组件改。

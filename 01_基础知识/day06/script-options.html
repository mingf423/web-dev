一、export default 整体结构（先有个印象）

组件就是一个对象，每个属性是一项职责。下面 6 个 section 逐个演示。

export default { name: "UserList", data() { return { ... }; }, // 状态 methods: { ... }, // 方法 computed: { ... }, // 计算属性 watch: { ... }, // 监听 created() { ... }, // 生命周期 }

二、data() —— 本地状态

变量定义在 data() 返回的对象里，模板里用 {{ }} 读。

data() { return { userName: '张三', age: 30, }; }
渲染结果：
姓名：{{ userName }}，年龄：{{ age }}
💡 为什么 data 是函数？组件被复用时，每个实例要独立的数据。函数每次 return 一个新对象，互不干扰。

三、methods —— 方法

@click 触发的方法定义在 methods 里，用 this.xxx 改数据。

methods: { increment() { this.count++; // this.count 访问 data }, }
渲染结果：
count = {{ count }}

四、computed —— 计算属性（派生值）

由 firstName + lastName 算出 fullName。改输入框，全名自动更新。

computed: { fullName() { return this.firstName + ' ' + this.lastName; }, }
渲染结果（模板里不带括号）：
姓：　名：
全名 = {{ fullName }}
💡 fullName 不是存出来的，是算出来的。firstName/lastName 一变，它自动重算。

五、watch —— 监听数据变化

监听 keyword，一变就记录「旧值 → 新值」。

watch: { keyword(newVal, oldVal) { this.watchLog = oldVal + ' → ' + newVal; }, }
渲染结果：
watch 记录的变化：{{ watchLog || '（还没变过）' }}
💡 watch 适合「数据一变就做动作」（如重新发请求），算新值则用 computed。

六、生命周期 —— created / mounted

组件创建后，Vue 会在特定时间点自动回调这些方法。打开 F12 Console 看执行顺序。

created() { // data 已就绪，DOM 还没渲染 → 适合发请求加载数据 this.lifecycleLog = 'created 执行了（data 就绪，DOM 未渲染）'; }, mounted() { // DOM 已渲染 → 可操作 DOM、初始化图表 this.lifecycleLog += '；mounted 执行了（DOM 已渲染）'; }
渲染结果：
生命周期日志：{{ lifecycleLog }}
💡 项目里最常见的是 created() { this.loadData() }——组件一创建就先加载数据。

computed 缓存 vs methods 重复计算

页面里同时渲染了 3 个 {{ fullName }}（computed）和 3 个 {{ getFullName() }}（methods）。 点「触发重渲染」按钮（改一个和姓名无关的变量 tick），观察两个计数器的变化。

computed: { // 只有 firstName/lastName 变了才会重新算，否则返回缓存 fullName() { this.computedCount++; return this.firstName + ' ' + this.lastName; }, }, methods: { // 每次被调用都重新执行一遍 getFullName() { this.methodCount++; return this.firstName + ' ' + this.lastName; }, }
姓：　名：
模板里渲染了 3 个 computed 和 3 个 methods（都是"姓 + 名"）：
{{ computedCount }} computed 计算次数（有缓存） {{ methodCount }} methods 计算次数（无缓存）
点这个按钮，tick 变了，整个组件重新渲染
页面实际渲染的内容：
computed × 3：{{ fullName }}　{{ fullName }}　{{ fullName }}
methods × 3：{{ getFullName() }}　{{ getFullName() }}　{{ getFullName() }}
💡 点「触发重渲染」：tick 变了 → 整个模板重新渲染 → 3 个 getFullName() 又各执行了一遍 （methodCount 一次 +3），而 3 个 fullName 因为依赖没变，直接读缓存（computedCount 不变）。
改姓或名：依赖变了，computed 才会重新算（computedCount 才会 +1）。

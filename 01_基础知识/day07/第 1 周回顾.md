### 🎯 一句话串起第 1 周

> 后端是「**命令式**」：你一步步告诉计算机怎么做（查库 → 组装 → 渲染）。
> 前端 Vue 是「**声明式 + 响应式**」：你只声明「页面显示什么数据」（模板），
> 数据一变，页面**自动**更新。你要做的就是在 `<script>` 里管理好数据，
> 在 `<template>` 里声明怎么显示。

## 2. 综合练习：用户列表页

> 用假数据（不写后端），做一个纯前端页面。浏览器直接打开就能跑。

### 需求

```
┌─────────────────────────────────────────────┐
│ 姓名：[____________]  [查询]  [重置]          │  ← 查询表单
├─────────────────────────────────────────────┤
│ 姓名    年龄    邮箱            操作          │
│ 张三    28    zhangsan@xx.com   [删除]        │  ← 表格
│ 李四    32    lisi@xx.com       [删除]        │
│ ...                                          │
│ （共 6 人）                                   │  ← 总人数
└─────────────────────────────────────────────┘
```

### 验收标准

1. **查询表单**：一个姓名输入框 + 「查询」「重置」按钮
2. **表格**：四列 —— 姓名、年龄、邮箱、操作
3. **搜索过滤**：输入「张」点查询，表格只显示名字含「张」的人；点重置恢复全部
4. **删除行**：点某行的「删除」，该行消失（建议加 `confirm` 确认）
5. **空状态**：搜不到人时，显示「没有匹配的用户」（而不是空白）
6. **总人数**（加分项）：显示「共 N 人」，随过滤/删除实时变化

## 3. 分步提示（先自己写，别急着看答案）

> 每步只给「做什么」和「用到第几天的知识」，**不给你完整代码**。卡住了就回头翻对应 Day 的指南。

### 第 1 步：搭 HTML 骨架（Day01）

- 一个 `<h2>` 标题 + 一个搜索区（`<input>` + 两个 `<button>`）+ 一个 `<table>`
- `<table>` 用 `<thead>`（表头）和 `<tbody>`（表体）

### 第 2 步：写 CSS 样式（Day02）

- 用第 1 周一直用的蓝色主题：主色 `#1b65b9`、背景 `#f1f2f6`、表头背景 `#f0f2f5`
- 表格加边框、行高、悬停高亮

### 第 3 步：准备假数据（Day03）

- 在 Vue 的 `data()` 里写一个 `users` 数组，6 个对象，每个含 `id` / `name` / `age` / `email`

### 第 4 步：挂载 Vue + 写 data（Day05 / Day06）

- 引入 Vue 2 CDN，`new Vue({ el: '#app', data() {...} })`
- `data()` 里放：`keyword`（输入框绑定）、`searchKeyword`（点查询后生效）、`users`

### 第 5 步：写模板语法（Day05）

- 输入框 `v-model="keyword"`（再加个 `@keyup.enter="search"` 按回车也能查）
- 「查询」`@click="search"`、「重置」`@click="reset"`
- 表格行 `v-for="u in filteredUsers" :key="u.id"`，四列 `{{ u.name }}` 等
- 删除按钮 `@click="remove(u.id)"`
- 空状态 `v-if="filteredUsers.length === 0"`
- 总人数 `{{ filteredUsers.length }}`

### 第 6 步：写逻辑（Day06）

- `computed.filteredUsers`：`users.filter(u => u.name.includes(this.searchKeyword))`（用 Day03 的 `filter` + `includes`）
- `methods.search`：`this.searchKeyword = this.keyword.trim()`
- `methods.reset`：清空 `keyword` 和 `searchKeyword`
- `methods.remove(id)`：`this.users = this.users.filter(u => u.id !== id)`（用 `confirm` 确认）

> 💡 **关键思路**：表格永远只渲染 `filteredUsers`（computed）。点「查询」只是改了 `searchKeyword`，
> `filteredUsers` 依赖它，于是**自动**重新过滤、自动刷新表格——这就是 Day05 说的「响应式」。

## 4. 参考答案讲解

> 写完了（或卡住了），对照 [user-list.html](./user-list.html)。下面是完整代码逐段讲解。

### 完整代码

```html
<div id="app">
  <!-- ① 查询表单 -->
  <div class="search-box">
    <input v-model="keyword" placeholder="输入姓名搜索" @keyup.enter="search" />
    <button class="btn" @click="search">查询</button>
    <button class="btn ghost" @click="reset">重置</button>
  </div>

  <!-- ② 表格 -->
  <table>
    <thead>
      <tr><th>姓名</th><th>年龄</th><th>邮箱</th><th>操作</th></tr>
    </thead>
    <tbody>
      <!-- ③ v-for 渲染每一行（只渲染过滤后的 filteredUsers） -->
      <tr v-for="u in filteredUsers" :key="u.id">
        <td>{{ u.name }}</td>
        <td>{{ u.age }}</td>
        <td>{{ u.email }}</td>
        <td><button class="btn danger" @click="remove(u.id)">删除</button></td>
      </tr>
      <!-- ④ 空状态：没数据时显示 -->
      <tr v-if="filteredUsers.length === 0">
        <td colspan="4" class="empty">没有匹配的用户</td>
      </tr>
    </tbody>
  </table>

  <!-- ⑤ 总人数 -->
  <div class="total">共 {{ filteredUsers.length }} 人</div>
</div>
```

```js
new Vue({
    el: '#app',
    data() {
        return {
            keyword: '',        // 输入框绑定的（还没生效）
            searchKeyword: '',  // 点「查询」后才生效的搜索词
            users: [
                { id: 1, name: '张三', age: 28, email: 'zhangsan@example.com' },
                { id: 2, name: '李四', age: 32, email: 'lisi@example.com' },
                { id: 3, name: '王五', age: 25, email: 'wangwu@example.com' },
                { id: 4, name: '赵六', age: 35, email: 'zhaoliu@example.com' },
                { id: 5, name: '孙七', age: 41, email: 'sunqi@example.com' },
                { id: 6, name: '周八', age: 29, email: 'zhouba@example.com' },
            ],
        };
    },
    computed: {
        // 过滤结果 = users 里 name 包含 searchKeyword 的那些
        filteredUsers() {
            return this.users.filter(u => u.name.includes(this.searchKeyword));
        },
    },
    methods: {
        search() {
            this.searchKeyword = this.keyword.trim();   // 把输入框的值"提交"为搜索词
        },
        reset() {
            this.keyword = '';
            this.searchKeyword = '';
        },
        remove(id) {
            if (confirm('确认删除该用户？')) {
                // 从 users 里删掉 id 匹配的那一个（Day03 的 filter）
                this.users = this.users.filter(u => u.id !== id);
            }
        },
    },
});
```

### 逐段串起来：这一页里知识点的映射

| 代码 | 知识点 | Day |
|------|--------|-----|
| `<table>` + `<thead>` + `<tbody>` | HTML 表格结构 | Day01 |
| `.search-box` / `table` 的蓝色主题样式 | CSS 选择器 + 颜色规范 | Day02 |
| `users: [{ id, name, age, email }]` | JS 对象数组 | Day03 |
| `users.filter(u => u.name.includes(...))` | `filter` + `includes`（≈ Stream.filter） | Day03 |
| `v-model="keyword"` | 双向绑定输入框 | Day05 |
| `v-for="u in filteredUsers" :key="u.id"` | 循环渲染表格行 | Day05 |
| `@click="search"` / `@keyup.enter="search"` | 绑定点击 / 回车事件 | Day05 |
| `v-if="filteredUsers.length === 0"` | 条件渲染空状态 | Day05 |
| `data()` 里的状态 | 本地状态 | Day06 |
| `computed.filteredUsers` | 计算属性（有缓存） | Day06 |
| `methods.search/reset/remove` | 方法 | Day06 |

### 完整数据流（这就是你要会「讲」的东西）

```
用户在输入框打字
  → v-model 更新 keyword（但表格还没变）
  → 点「查询」→ search() 把 keyword 提交给 searchKeyword
  → searchKeyword 变了 → computed.filteredUsers 依赖它，自动重新 filter
  → filteredUsers 变了 → v-for 自动重新渲染表格
  → 总人数 {{ filteredUsers.length }} 也自动更新
```

> 你注意到了吗？**你没有写任何「刷新表格」的代码**。只改了 `searchKeyword`，
> Vue 就自动把该重算的重算、该重画的重画——这就是第 1 周最核心的收获：**响应式**。

## 6. 第 1 周速查表（精华版）

### Vue 模板语法（Day05）

```
{{ xxx }}        显示值
v-if / v-show    条件渲染
v-for="x in list" :key="x.id"   循环渲染
v-model          双向绑定（输入框）
:xxx="var"       传变量给属性
@xxx="fn"        绑定事件
```

### Vue 组件选项（Day06）

```
data()     存状态（必须是函数）
methods    写方法（@click 触发）
computed   算新值（有缓存，模板不带括号）
watch      盯变化（一变就执行动作）
props      父传子（只读）
$emit      子传父（抛事件）
created    发请求加载数据
```

### JS 数组方法（Day03）

```
list.map(x => ...)     转换每个元素（≈ Stream.map）
list.filter(x => ...)  过滤（≈ Stream.filter）
list.find(x => ...)    找第一个匹配（≈ 手动循环 return）
```

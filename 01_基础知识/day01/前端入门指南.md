## 1. HTML 结构 —— 前端的"类定义"

```html
<!DOCTYPE html>
<html lang="zh">
<head>
    <meta charset="UTF-8">
    <title>Java 开发者的前端第一步</title>
</head>
<body>
    <!-- 页面可见内容写在这里 -->
</body>
</html>
```

### Java 类比

| 前端概念 | Java 类比 | 说明 |
|----------|-----------|------|
| `<html>` | `class` 关键字 | 整个页面的根容器 |
| `<head>` | 类的 `import` 区 + 注解 | 元信息、样式、脚本声明，不直接渲染 |
| `<body>` | 类的 `main` 方法体 | 用户**能看到**的所有内容 |
| `<!DOCTYPE html>` | 编译器版本声明 | 告诉浏览器"按 HTML5 标准解析" |
| `<meta charset="UTF-8">` | `Charset.forName("UTF-8")` | 字符编码，避免中文乱码 |

### 🎯 关键认知

> HTML **不是编程语言**，它是**标记语言**。想象你在用 XML 定义 UI 布局 —— 用标签声明"这里有个按钮、这里有个标题"，不用写逻辑。

## 2. CSS —— 前端的"样式属性"

```html
<style>
    body {
        font-family: system-ui;
        max-width: 500px;
        margin: 100px auto;
        text-align: center;
    }
</style>
```

### 语法拆解

```
选择器 {
    属性: 值;
    属性: 值;
}
```

### Java 类比

| CSS 概念 | Java 类比 | 说明 |
|----------|-----------|------|
| `body` | 对象引用 | 选中页面上所有 `<body>` 元素 |
| `{ }` | `{ }` | 一样，都是代码块 |
| `font-family: system-ui` | `setFont(...)` | 设置字体 |
| `max-width: 500px` | `setMaxWidth(500)` | 最大宽度 500 像素 |
| `margin: 100px auto` | 上下边距 100px，左右自动（=居中） |
| `text-align: center` | 文字水平居中 |

### 🎯 关键认知

> 前端三大件的分工：
> - **HTML** = 有什么（内容/结构）
> - **CSS** = 长什么样（样式/布局）
> - **JavaScript** = 怎么动（交互/逻辑）

像 Java Swing 里：HTML ≈ 你在 `JFrame` 上放了什么组件，CSS ≈ `setSize()`/`setBackground()`，JS ≈ `addActionListener()`。

## 3. JavaScript 基础 —— 你已会的（大部分）

### 3.1 变量声明

```js
const greetBtn = document.getElementById('greetBtn');   // 不可重新赋值
const greeting = document.getElementById('greeting');   // 不可重新赋值
const nameInput = document.getElementById('nameInput');  // 不可重新赋值
```

| JS | Java | 说明 |
|----|------|------|
| `const` | `final` | 不可重新赋值（但对象内部属性可变） |
| `let` | 普通变量 | 可以重新赋值 |
| `var` | ~~不要用~~ | 老语法，有作用域陷阱 |

```js
// Java 对比
// Java:        final String name = "张三";
// JavaScript:  const name = "张三";
//
// Java:        String name = "张三";
// JavaScript:  let name = "张三";
```

### 3.2 函数 / 方法

```js
greetBtn.addEventListener('click', function() {
    // 这是匿名函数（≈ Java 的 Lambda）
    const name = nameInput.value;
    if (name.trim()) {
        greeting.textContent = `你好，${name}！`;
    }
});
```

Java 对比：

```java
// JavaScript 匿名函数
button.addEventListener("click", () -> {
    String name = input.getValue();
    if (!name.isBlank()) {
        label.setText("你好，" + name + "！");
    }
});

// 相当于 Java 的：
greetBtn.addActionListener(new ActionListener() {
    @Override
    public void actionPerformed(ActionEvent e) {
        String name = nameInput.getValue();
        // ...
    }
});
```

### 3.3 模板字符串 —— 前端的字符串格式化

```js
`你好，${name}！`          // JavaScript：反引号 + ${}
```

```java
String.format("你好，%s！", name)   // Java：String.format + %s
```

### 🎯 关键认知

> JavaScript 是**弱类型**、**动态**语言。没有 `int`/`String` 类型声明，一个 `let` 走天下。刚开始会觉得"不安全"，习惯了会很灵活。

## 4. DOM 操作 —— 前端的"操控页面 API"

DOM = **Document Object Model**，浏览器把 HTML 解析成一颗**对象树**，你操作这棵树 = 操作页面。

### 4.1 查找元素（≈ Java 的 findById）

```js
document.getElementById('greetBtn')        // 按 id 查找，返回单个元素
document.querySelector('.my-class')        // 按 CSS 选择器查找，返回第一个
document.querySelectorAll('div')           // 查找所有，返回 NodeList（≈ List）
```

Java 对比：

```java
// Java MyBatis:   mapper.findById(1L)
// JavaScript DOM:  document.getElementById('greetBtn')
```

### 4.2 读取/修改内容

```js
// 读取输入框的值（input 用 .value）
const name = nameInput.value;

// 修改元素的文本
greeting.textContent = '请输入名字后再点我！';

// 更常用的：修改 HTML 内容
element.innerHTML = '<strong>加粗文字</strong>';
```

### 4.3 事件监听（≈ addListener）

```js
// JavaScript
element.addEventListener('事件名', 回调函数);
element.addEventListener('click', function() { ... });        // 点击
element.addEventListener('input', function() { ... });        // 输入
element.addEventListener('change', function() { ... });       // 值变化
element.addEventListener('submit', function(e) {
    e.preventDefault();  // 阻止默认行为（阻止表单提交）
});
```

Java 类比：

| JS 事件 | Java Swing 事件 |
|---------|-----------------|
| `click` | `ActionListener.actionPerformed()` |
| `input` | `DocumentListener.insertUpdate()` |
| `change` | `ItemListener.itemStateChanged()` |
| `keydown` | `KeyListener.keyPressed()` |

## 5. Bug 复盘 —— 你刚才遇到的 `Cannot read properties of null`

```js
const nameInput = document.getElementById('nameInput');  // → null！
const name = nameInput.value;  // 💥 空指针，等价于 Java 的 NullPointerException
```

### Java 对比

```java
// Java
User user = userDao.findById(999L);  // 返回 null
String name = user.getName();        // 💥 NullPointerException

// 防御式编程
if (user != null) {
    String name = user.getName();
}
```

```js
// JavaScript 防御式
const nameInput = document.getElementById('nameInput');
if (nameInput) {
    console.log(nameInput.value);
}
```

### 🎯 根因

JS 在 HTML **之前**就执行了，或者 DOM 中根本**没有**这个 id 的元素。两种常见情况：

| 原因 | 解决方案 |
|------|----------|
| 元素不存在 | 先写 HTML 元素，再写 JS |
| JS 执行早于 HTML 渲染 | 把 `<script>` 放在 `</body>` 前面，或用 `DOMContentLoaded` 事件 |

## 6. 数据流全景图

```
用户输入 "张三"
    │
    ▼
┌──────────────────────────────────────────┐
│  <input id="nameInput" />                 │   ← HTML 定义结构
│  nameInput.value  →  "张三"              │   ← JS 读取值
└──────────────────────────────────────────┘
    │
    ▼
┌──────────────────────────────────────────┐
│  greetBtn.addEventListener('click', () => {│
│      greeting.textContent = `你好，张三！` │   ← JS 修改 DOM
│  })                                       │
└──────────────────────────────────────────┘
    │
    ▼
┌──────────────────────────────────────────┐
│  <h1 id="greeting">你好，张三！</h1>      │   ← 页面自动重绘
└──────────────────────────────────────────┘
```

### 与 Java 后端对比

| 步骤 | Java 后端 | 前端 JS |
|------|-----------|---------|
| 接收输入 | `request.getParameter("name")` | `element.value` |
| 处理逻辑 | Service 层 | 事件回调函数 |
| 返回结果 | `response.getWriter().write(json)` | `element.textContent = ...` |

> 前端本质就是：**读 DOM → 处理 → 写 DOM**，只是没有了"请求-响应"的边界，所有操作都是在用户浏览器里完成的。

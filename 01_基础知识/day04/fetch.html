fetch 调用真实接口（JSONPlaceholder 免费假数据）

打开本页会自动调用 https://jsonplaceholder.typicode.com/users（10 个假用户）。 打开 F12 → Network，能看到这条请求完整的 request/response。

// ① fetch 发请求，返回 Promise<Response> fetch('https://jsonplaceholder.typicode.com/users') .then(res => { // ② 检查状态码（res.ok = 200~299） if (!res.ok) throw new Error('HTTP ' + res.status); // ③ 把 Response 转成 JSON（关键两步！） return res.json(); }) .then(users => { // ④ 拿到数据，渲染到表格 renderTable(users); }) .catch(err => { // ⑤ 任何一步出错都到这 showError(err.message); });

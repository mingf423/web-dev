一、执行顺序：同步先跑，异步后跑（最重要的心智模型）

观察下方输出出现的顺序。注意「3. 定时器回调」是最后才出现的 —— 因为它是异步的。

console.log('1. 开始'); // 同步，立刻执行 setTimeout(() => { // 异步，1 秒后才执行 console.log('3. 定时器回调（异步）'); }, 1000); console.log('2. 结束'); // 同步，立刻执行

💡 Java 里代码从上往下顺序执行；JS 里同步的先跑完，异步的「回头」再跑。这就是为什么 fetch(url).then(...) 里的回调不会立刻执行。

二、Promise 成功：resolve → then

模拟「后端接口 1 秒后返回成功」。resolve 对应成功，then 处理结果。

const p = new Promise((resolve, reject) => { // 模拟异步操作：1 秒后成功 setTimeout(() => resolve('数据加载成功'), 1000); }); p.then(result => { console.log('then 收到：' + result); });

三、Promise 失败：reject → catch

reject 对应失败，catch 处理错误。这就是项目里 .catch(err => this.$message.error(...)) 的原理。

const p = new Promise((resolve, reject) => { setTimeout(() => reject(new Error('网络请求失败')), 1000); }); p.then(result => { // 不会执行，因为失败了 }).catch(err => { console.log('catch 捕获：' + err.message); });

四、then 链式调用（项目三步曲）

模拟项目里「拿数据 → 处理 → 渲染」三步。每个 then 的返回值传给下一个。

// 模拟一个返回 Promise 的「接口函数」 function mockFetch() { return new Promise(resolve => { setTimeout(() => resolve({ code: 0, data: { list: [1,2,3] } }), 800); }); } mockFetch() // ① 发请求，拿到 Promise .then(res => { // ② 校验 code if (res.code === 0) return res.data; throw new Error('code 非 0'); }) .then(data => { // ③ 拿到 data，渲染 console.log('渲染列表：' + data.list); }) .catch(err => { // ④ 任何一步出错都到这 console.log('出错了：' + err.message); });

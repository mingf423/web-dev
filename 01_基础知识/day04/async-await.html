一、then 链 vs async/await：做同一件事

左右对比：功能完全一样，都是「请求 → 校验 → 打印」。async/await 版更接近你熟悉的 Java 同步代码。

// ① then 链写法（回调嵌套，容易乱） function loadThen() { fetch(API) .then(res => res.json()) .then(data => { console.log('then 拿到：', data); }) .catch(err => { console.error(err); }); } // ② async/await 写法（看起来就是同步代码） async function loadAwait() { try { const res = await fetch(API); // await = 等结果，不阻塞 const data = await res.json(); console.log('await 拿到：', data); } catch (err) { // 用 try/catch 抓错！ console.error(err); } }

二、async 函数永远返回 Promise

async 标记的函数，即使内部 return 普通值，调用方拿到的也是 Promise。

async function getName() { return '张三'; // 会被自动包成 Promise } // 所以能这样用： getName().then(name => console.log(name)); // 或者： const name = await getName(); // 在 async 函数里 await
